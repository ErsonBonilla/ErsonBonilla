### 💼 Proyectos Destacados

- 🤖 **[PlagIA](https://github.com/ErsonBonilla/PlagIA)**
  * **Descripción:** Solución basada en Inteligencia Artificial y Procesamiento de Lenguaje Natural (NLP) diseñada para la detección de similitudes semánticas y análisis de coincidencias en documentos.
  * **Stack:** Python, NLP, AI Models, REST APIs.

- 📊 **[SIAUGESMAT](https://github.com/ErsonBonilla/SIAUGESMAT)**
  * **Descripción:** Sistema integral de información orientado a la centralización, administración y procesamiento operativo de registros institucionales.
  * **Stack:** Python, SQL, Base de Datos Relacionales, Web Architecture.

- ☕ **[Maicofi](https://github.com/ErsonBonilla/Maicofi)**
  * **Descripción:** Plataforma web enfocada en la gestión modular de procesos y optimización de flujos de interacción con el usuario.
  * **Stack:** Python, JavaScript, HTML/CSS, Git.

- ⚙️ **SIET**
  * **Descripción:** Pipeline de datos serverless en la nube que ingiere datos de fuentes externas, aplica transformaciones en tiempo real y centraliza la analítica en BigQuery.
  * **Stack:** GCP (Cloud Functions, Pub/Sub, BigQuery), Python, SQL.
